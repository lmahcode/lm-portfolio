# Lily Mah Portfolio

React + Vite portfolio starter based on the supplied Figma layout.

## Run

1. Install Node.js.
2. Open this folder in VS Code.
3. Run:

   npm install
   npm run dev

4. Open the local Vite address shown in the terminal.

## Add your images

Put your files in:

src/assets/

Use these filenames for the easiest setup:

- project1.jpg
- project2.jpg
- project3.jpg
- project4.jpg
- project5.jpg
- profile.jpg

The Home page uses a horizontal gallery. When the mouse is over the grey gallery, the mouse wheel is converted to horizontal scrolling.

The navigation changes between Home, My Portfolio, and About Me with animated positioning of the Lily Mah heading.
